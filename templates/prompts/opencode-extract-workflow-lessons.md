# Opencode Prompt: Extract Workflow Lessons

Purpose: Guide an agent to compare old and new workflow patterns.

## Prompt

Task: compare earlier and newer Noqlen workflow patterns safely.

Rules:

- Compare safely and constructively.
- Avoid blame language.
- Extract reusable lessons.
- Create sanitized examples only.
- Do not copy private details, local paths, secrets, lyrics, fingerprints, real library paths, or full configs.
- Propose future improvements as workflow patterns, not product refactors.

Output:

- Observed workflow pattern.
- How the current playbook handles it.
- Reusable prompt or example idea.
- Risk reduced by the improved workflow.
