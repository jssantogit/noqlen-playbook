# Opencode Prompt: Audit Block

Purpose: Audit a completed block.

## Prompt

Inspect the diff and do not make changes unless explicitly asked.

Requirements:

- Compare against the spec.
- Check tests and validation evidence.
- Check security risks.
- Check repo hygiene.
- Check boundaries and scope.
- Report findings by severity.

Output: checks performed, findings, required fixes, optional improvements, validation gaps, and final status.
