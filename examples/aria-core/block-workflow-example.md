# Aria Core Block Workflow Example

This example uses Aria Core only to show the workflow pattern. It does not define new product requirements.

## Block goal

Document an existing app/core contract boundary.

## Scope

Describe inputs, outputs, and validation expectations for one boundary.

## Allowed files

- Relevant spec or documentation files.

## Forbidden files

- Core implementation files.
- UI implementation files.
- Release files.

## Validation

- Run repository documentation checks.

## Audit trigger

Audit if the block changes public contract language or app/core boundaries.

## Stop condition

Stop if implementation changes are required or undocumented behavior is discovered.
