# Tooling Radar

This radar tracks workflow accelerators without turning tooling into the workflow.

## Recommended

- OpenCode native: baseline agent capabilities, explicit permissions, manual or disabled share for real Noqlen work.
- Serena: highest-value accelerator for semantic navigation. Use read-only first; edit only inside explicit allowed files.
- RTK: useful for shell-heavy blocks. Compressed output is not audit proof.

## Pilot

- Context Mode: useful for long sessions, tool-output routing, exploration, and large outputs. Treat OpenCode support as pilot/partial until validated locally.

## Restricted

- Caveman: optional and disabled by default. Allowed only for temporary concise conversation/status. Forbidden for specs, ADRs, audit reports, handoffs, release notes, public docs, and architectural decisions.

## Watchlist

- opencode-daytona.
- opencode-devcontainers.
- opencode-vibeguard.
- opencode-morph-plugin.
- oh-my-opencode.
- Future MCP tools.

## Evaluation Criteria

- Maintenance.
- Security posture.
- Local/offline behavior.
- Config contamination risk.
- Evidence preservation.
- Opencode compatibility.
- Measurable workflow improvement.
- Failure modes.
- Rollback path.
